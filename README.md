# SITE-05 Weapons

The weapon list for the SITE-05 VRChat world.

- **weapons.txt** - one weapon per line: `number | Name | damage | headshot | max rounds per second | range (m)`.
- The SITE-05 Gear Installer downloads this file (Weapons dropdown > Refresh) to list the weapons you can register a gun as.
- A weapon's number is permanent: never reuse or renumber it. Delete a line and guns registered as that weapon stop doing damage; add `| retired` to stop new registrations but keep existing guns working.
